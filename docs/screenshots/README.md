# Screenshots Directory

Save your actual PNG dashboard screenshots in this directory with the following filenames to render them automatically in the root `README.md`:

- `overview.png` — Overview tab showing live telemetry & risk gauge
- `predictions.png` — AI Predictions page showing SHAP explanations
- `advisory.png` — Actionable Operational Advisory cards & live prompt banner
- `simulator.png` — What-if Digital Twin Simulator sliders
- `correlations.png` — Correlation Explorer SVG network graph
